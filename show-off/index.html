the-eye is an MCP server for macOS. It gives an agent the one thing a screenshot cannot: what the screen showed over time. Every frame, every freeze, the spring behind a motion, and who was late.

This page is doing it to itself. Each tick around the eye is one frame this page drew. Make it miss some.

Five tools.
One of them acts.

    
There were thirteen. An agent had to start a recording, take the lock, load a probe, move, stop, and remember the order. Now the agent opens one session and says where to go. The other four only look.

  


  

    

      
eye_drive

      
A hand, an eye and a witness inside the app, in one call.

      
It opens one session on your app. The window is recorded at every display refresh. Your trackpad and keyboard are held, so nothing collides with the hand. In a Debug build a probe goes inside and logs every layer on the same clock as the frames.

      
Then you say where to go. A line of words is one unbroken motion at 120Hz, and things are called by their names. The hand presses a thing only if that thing is what is under the pointer.

      
End it, and it answers with what a viewer would have noticed, worst first: the freeze, how long it lasted, and the function that was blocking the main thread.

    

    

      
// open, and move
eye_drive {
  app: "YourApp",
  wing: '"New note" tap  "Title" tap  settle'
}

// exact, when words are not enough
eye_drive { steps: [
  { op: "scroll", dy: -400, momentum: true },
  { op: "wait_until", expr: "!moving" }
] }

// only watch: no hand, input stays yours
eye_drive { app: "YourApp", hands: false }

// what did all of that look like?
eye_drive { end: true }

    

    
    
      
  • The probe goes in by itself. Once per launch. When it cannot, one line says why and the session goes on.
    • 
      
  • Frames come back with the words. The frame the screen settled on after every call, and the recorded frame at each defect.
    • 
      
  • The window comes forward, then goes back. Also from minimized, with everything that was above it restored.
    • 
      
  • It lets go by itself. Thirty seconds without a call ends the session and returns your input. Esc six times in a row takes it back sooner.

eye_snapshotOne look.

      
A region as it is, or an app's window even when it is covered or minimized: raised, pictured and put back exactly, in under half a second. A still frame comes with what it says: text sizes and contrast, corner shapes, edges that miss a line by a point.

    

    

      
eye_inspectWhat the app says it is.

      
The accessibility tree of an app, one line per element with its bounds, or everything the element under a point exposes. Nothing is recorded and nothing moves.

    

    

      
eye_reportAny run, read again.

      
The timeline. The worst gaps, each joined with where the cursor was, which element it was over, which step was running and what the main thread was doing. Two runs side by side. One layer, from inside.

    

    

      
eye_statusWhat it sees right now.

      
Displays and their refresh rates, who holds the screen, and the open session live: moving or still, how far, and what a viewer noticed in the last few seconds.

    

  






  
Put it under your agent.

  

    claude mcp add the-eye -- node src/index.ts
    
  

  
Needs macOS 14 or later, Node 23.6 or later, and the Xcode command-line tools. The terminal or agent that runs it needs Screen Recording and Accessibility permission. The native helper builds itself on first start.
